모델 진화 타임라인

V7 — 전처리 다양성 (Preprocessing Diversity)

동일한 64개 feature에 결측치 처리만 다르게: A(그룹 중앙값), B(feature 제거), C(이진 지시자). 결과: 예측 상관 0.999, 오차 상관 0.992 → Stacking 완전 무의미. 사실상 단일 모델 3번 복제.

V8 — 정보 다양성 (Information Diversity)

교수님 조언에 따라 feature set 자체를 분리: A(Lag 17개), B(Macro 21개), C(Event/Season 40개). 공유 feature 6개만. 결과: 오차 상관 0.61 → Stacking이 처음으로 작동! Ridge Meta가 RMSE 12.6% 추가 개선. 한계: Meta 가중치를 2024 테스트로 학습 → 정보 누출.

V9 — Rolling Window OOF (Out-of-Fold)

V8 정보 다양성 유지 + Meta 학습 방식 개선. 시간 순서 확장 윈도우(4 fold)로 OOF 예측값 생성, 이로 Meta 가중치 학습. 결과: 오차 상관 0.26, 가중치 A=57%/C=38% 균형. 한계: 비COVID 데이터 42개월 → 데이터 부족으로 2025 예측력 저하.

각 모델의 "질문"

A "지난달에 몇 명 왔으니까 이번 달은 몇 명 올까?"

B "환율이 싸지고 유가가 내려갔으니 더 올까?"

구조 변화(Structural Break)란?

시계열에서 데이터를 생성하는 과정(DGP) 자체가 바뀌는 것. 사드 이전의 "중국 800만 시대"와 이후의 "다변화 시대"는 서로 다른 DGP이므로, 옛 데이터를 학습에 포함하면 현재 구조에 맞지 않는 패턴이 noise로 작용한다.

V9가 2025 예측에서 부진한 이유

V9의 2025 예측이 나쁜 것은 방법론 문제가 아니라 데이터 부족 + Model C 폭발 때문이다.
• Model C가 2025-01 특정 국가에서 ~9M 예측 (비현실적) → Clipping으로도 완전 해결 불가
• OOF로 학습된 가중치(A=57%, C=38%)가 이 폭발을 억제하지 못함
• 반면 V8의 Ridge Meta(C=97%)는 전체 데이터로 학습했기에 C의 정상적인 예측만 반영
→ 데이터가 충분하면 V9 방식이 확실히 우월하지만, 현재 42개월로는 V8이 실용적.

왜 OOF에서 오차 상관이 더 낮아지는가?

전체 데이터로 학습하면 모든 모델이 충분한 정보를 가지므로 예측이 수렴한다. 제한된 학습 데이터(OOF)로 학습하면 각 모델이 자기 feature만으로 "버둥거려야" 하므로, 관점 차이가 극대화된다. 비유: 시험 범위를 다 공부한 학생들은 비슷하게 틀리지만, 각자 다른 챕터만 공부한 학생들은 다른 문제에서 틀린다.

V8의 C=97%가 나쁜 이유

단일 모델에 97% 의존하면 앙상블의 의미가 사라진다. Model C가 폭발하면 전체가 폭발한다. V9의 A=57%/C=38%는 Model A의 안정성과 Model C의 설명력을 균형있게 결합한다. "최고의 앙상블은 하나가 틀려도 다른 것이 보완하는 것" — V9가 이 철학에 더 부합한다.

V7 → V8 → V9 진화 요약

무엇을 배웠는가

1. 정보 다양성 > 전처리 다양성
같은 feature에 전처리만 바꾸면 corr 0.999. Feature set을 바꾸면 error corr 0.61.

2. Error Correlation이 진짜 지표
Prediction correlation은 항상 높다(같은 target). Error correlation이 낮아야 Stacking 가능.

3. Simple Average의 위력
정보 다양성이 확보되면, 단순 평균만으로도 개별 모델 대비 MAPE 2~10%p 개선.

4. 데이터 양 < 데이터 품질
2015~2017 데이터는 구조 변화(사드) 이전이라 포함하면 오히려 해롭다.

5. COVID는 시간이 해결
42개월 공백의 lag 오염은 모델로 해결 불가. 2026년 이후 자연 해소.

향후 개선 방향

단기 (현재)
V8 Ridge Meta를 실전 예측에 사용. V9의 방법론적 정당성을 보고서에 기록.

중기 (2026년)
2025년 데이터 축적 → V9 OOF에 사용 가능 개월 수 증가 → 성능 개선 기대.

장기 (2027년~)
COVID lag 오염 완전 해소 (2020~2023 참조 lag 사라짐). V9 방식이 V8 역전 예상.

구조적 개선
• Feature set 4~5개로 확장 (날씨 전용, 한류 전용 등)
• LightGBM/XGBoost 등 고성능 learner 도입
• Bayesian Meta Learner로 불확실성 정량화
