Strategy 1: Prediction Blending

두 모델의 예측값을 직접 섞는 가장 단순한 방법. "두 의사의 소견을 평균 내는" 접근.

왜 V8 Ridge + V9 Model A인가?

V8 Ridge Meta: Model C 위주(97%). Event/Season/Culture 관점 예측. 문화 이벤트 패턴에 강함.

V9 Model A: Lag/History 관점 예측. 과거 방문 패턴의 관성에 강함. OOF로 학습되어 폭발 없이 안정적.

결합 효과: V8이 "문화/이벤트"로 틀리는 구간에서 V9가 "과거 패턴"으로 보정하고, V9가 "lag만으로 부족한" 구간에서 V8이 보정.

50:50이 최적인 이유

V8 Ridge(C 위주)와 V9 Model A(Lag 위주)는 정보 구조가 완전히 다르다. V8이 과대예측할 때 V9A가 과소예측하고, 반대도 마찬가지. 이 "오차의 음의 상관"이 평균으로 상쇄. 이건 교수님이 말씀하신 "정보 다양성" 원리가 모델 버전 사이에서도 작동하는 것!

가중치 비교: V8 vs V10-Constrained

왜 이 가중치가 더 좋은가

V8 (C=97%): Model C 하나에 올인. C가 맞으면 좋지만, C가 틀리면 보정 불가.

V10 (A=40%, C=55%): C의 설명력은 유지하되, A(Lag)가 40% 보정. C가 폭발해도 A가 완충 역할.

핵심 차이: V8은 "C를 믿어"이고, V10은 "C를 믿되 A로 보험을 들어". 보험의 비용은 RMSE 약간 증가지만, MAPE는 25.1% → 16.8%로 대폭 개선.

Strategy 3: Bayesian Update

V9 OOF = 사전 믿음(Prior), 2024 성능 = 새 증거(Likelihood) → 베이지안 업데이트로 사후 가중치(Posterior) 도출.

Posterior (V10)
